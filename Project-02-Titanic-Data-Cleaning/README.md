# Titanic Data Cleaning & Passenger Analysis

## Project Title

**Titanic Data Cleaning & Passenger Analysis**

## Project Overview

This project focuses on cleaning and analyzing the Titanic dataset to understand passenger survival trends based on age, gender, and passenger class.

## Dataset Information

**Dataset:** Titanic Dataset

**Source:** Kaggle

**Link:** https://www.kaggle.com/datasets/yasserh/titanic-dataset

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Installation Steps

```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run

1. Download the dataset from Kaggle.
2. Open the notebook in Google Colab.
3. Upload the CSV file.
4. Run the code cells step by step.
5. Analyze the results and visualizations.

## Results

* Missing values were identified and handled.
* Duplicate records were removed.
* Age outliers were detected and treated.
* Data was filtered, sorted, and grouped.
* Survival statistics were calculated.
* Visualizations were created to understand survival trends.

## Conclusion

The project successfully demonstrates data cleaning, statistical analysis, filtering, grouping, and visualization using Python. It helped identify survival patterns among Titanic passengers.
