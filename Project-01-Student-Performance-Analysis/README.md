# Student Performance Analysis

## Project Title

**Student Performance Analysis**

## Project Overview

This project analyzes student academic performance using Exploratory Data Analysis (EDA). It focuses on data cleaning, statistical analysis, correlation, outlier detection, and visualization.

## Dataset Information

**Dataset:** Student Performance Dataset
**Source:** Kaggle
**Kaggle Link:** https://www.kaggle.com/datasets/devansodariya/student-performance-data

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Installation Steps

Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

## How to Run

1. Open the project in Google Colab.
2. Upload the student dataset.
3. Import the required libraries.
4. Run the code cells step by step.
5. View the analysis results and visualizations.
