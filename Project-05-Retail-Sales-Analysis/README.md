## Project Title

**Retail Sales Analysis Dashboard**

## Project Overview

This project analyzes the Superstore Sales dataset using Exploratory Data Analysis (EDA). The analysis focuses on understanding sales, profit, product categories, regions, and sales trends to generate useful business insights.

The project includes data cleaning, missing-value analysis, outlier detection, statistical analysis, filtering, sorting, GroupBy operations, and data visualization.

## Dataset Information

**Dataset:** Superstore Sales Dataset

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

The dataset contains information related to retail orders, including sales, profit, quantity, discount, region, category, product name, and order date.

1. Install Python on your system.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Alternatively, the project can be run directly in **Google Colab**, where these libraries are generally available.

## How to Run

1. Download the Superstore dataset from Kaggle.
2. Open the project notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset.
4. Import the required Python libraries.
5. Run the notebook cells sequentially.
6. View the statistical results, visualizations, and business insights.
